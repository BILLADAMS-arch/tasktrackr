 ## TaskTracker

TaskTracker is a simple and efficient React to-do app that lets users manage their daily tasks. Add, edit, delete, complete, and filter your tasks — all stored locally in your browser.

## Features

Add new tasks
Edit tasks in-place
Delete tasks
Mark tasks as completed
Filter by all / active / completed
Task persistence with localStorage
Page navigation with React Router DOM

## Built With
React
React Router DOM
npm install react-router-dom
CSS for styling
localStorage for data persistence

## Getting Started

To run the app locally:
git clone https://github.com/BILLADAMS-arch/tasktrackr
cd tasktracker
npm install
npm start
Then open http://localhost:3000 in your browser.
